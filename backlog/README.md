# workloop Backlog

Structured specification, architecture decision records (ADRs), milestones, and
task cards managed via [`backlog.md`](https://github.com/MrLesk/Backlog.md)
(`pixi run backlog`).

## Structure

- `docs/doc-1 - workloop-specification.md` — full functional specification for
  the four-verb lifecycle, localhost failover proxy, review modes, and
  self-dogfooding bootstrap.
- `decisions/` — Architecture Decision Records (`decision-1` through
  `decision-6`).
- `milestones/` — `m-0` (Scaffold & Gates), `m-1` (Proxy & Four-Verb Lifecycle),
  and `m-2` (Pluggable Review & Self-Dogfooding).
- `tasks/` — individual deliverable cards (`WKL-001` through `WKL-004`).
